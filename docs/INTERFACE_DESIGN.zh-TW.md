# 介面設計

[English](INTERFACE_DESIGN.md) | **繁體中文**

App 採深色、以 3D 為主的介面：相機畫面或點雲佔滿螢幕，控制項以深色玻璃浮在上方。每個畫面只有一個醒目的主要動作，次要控制較低調，且只在當下步驟用得到時才出現。本頁說明共用設計系統、各畫面與檢查方式；掃描、處理與匯出流程沒有改變。

## 設計系統

`arkit-3dgs-scanner/Design/DesignSystem.swift` 集中定義 token 與元件；`Capture/UI/HUDStyle.swift` 保留疊在相機上的深色玻璃（`hudGlass`）與帶陰影文字（`hudText`）。

| Token | 數值 |
| --- | --- |
| 間距（`DS.Space`） | 4、8、12、16、20、24、32 pt |
| 圓角（`DS.Radius`） | 12、16、22、28 pt |
| 尺寸（`DS.Size`） | 觸控目標至少 44 pt、主要按鈕 52 pt、快門 78 pt、面板最寬 560 pt |
| 顏色（`DS.Palette`） | 底色、表面與描邊；文字為 100／64／40% 白；空間感青色強調色（也是資產目錄的 accent），上面的文字用深色；錄製紅；成功、警告、危險與資訊 |

App 根層套用深色模式與強調色。點雲檢視器使用相同底色，讓場景與介面看起來是同一個平面。

| 元件 | 用途與狀態 |
| --- | --- |
| `DSPrimaryButtonStyle` | 畫面的主要動作。按下（縮小變暗）、游標懸停（浮起）、載入中（顯示轉圈，維持強調色）、停用（不透明灰色，不會透出後方內容） |
| `DSSecondaryButtonStyle` | 次要動作的玻璃膠囊，有按下、懸停與停用狀態 |
| `DSIconButtonStyle` | 44 pt 圓形玻璃按鈕；`isSelected` 標示開啟中的切換，`foreground` 為破壞性動作上色 |
| `DSStatusPill` | 狀態與提示膠囊，含語氣（中性、強調、成功、警告、危險、資訊）與可選的閃爍錄製點 |
| `DSMetric` | 幀數、點數與模式的圖示＋數值小標籤 |
| `DSSegmentedPicker` | 浮動分段選擇器，選取項以強調色滑動 |
| `DSProgressRing`、`DSToast` | 確定進度環；短暫的成功提示 |
| `DSFlowLayout` | 標籤排不下時換行，不會被截斷 |
| `dsCard`、`dsFloatingPanel`、`dsCanvas` | 底色上的卡片、浮在場景上的面板，以及 App 背景 |

觸覺回饋使用 SwiftUI sensory feedback：開始與結束掃描、處理或匯出完成、拍攝被暫停時的警告，以及紀錄選取變更。

## 畫面

### 首頁

首頁顯示掃描模式（LiDAR 或標準相機）、簡短介紹，以及標示已存筆數的「掃描紀錄」卡片。「開始掃描」浮在底部，並註明處理都在裝置上進行；不支援 AR 的裝置上，開始鍵停用並附說明。
- 工具列有語言選單（地球圖示與目前語言）和操作指南（**?**）。
- 存下第一筆掃描之前，首頁會顯示三個步驟。

### 掃描紀錄

點選卡片才會開啟掃描紀錄。
- **版面：** 以封面格狀排列，顯示日期、影像數與點數；徽章標示 LiDAR 掃描與已有分享檔案的掃描。iPhone 為兩欄，iPad 封面較大。
- **選取：** 「選取」會切換成多選，操作列只在選取時出現，提供「全選」與「刪除所選」。全部選取後刪除即為「全部刪除」，確認視窗會標明。
- **刪除：** 長按封面可「刪除」。所有刪除仍需確認。
- **沒有紀錄時：** 頁面會說明還沒有掃描紀錄，並提供「返回開始掃描」。

### 掃描 HUD

- **上方列：** 關閉鍵、置中的狀態膠囊，以及掃描中的即時數據（幀數、點數、預估容量；相機模式另標示 LiDAR 關閉）。
- **提示插槽：** 一次只顯示優先度最高的一則。遮斷級警告同時顯示紅框並觸發警告回饋。
- **工具列：** 點雲、熱圖與空間結構切換。只在掃描中出現，位於右側（橫向在左側）。
- **快門：**
  - LiDAR 掃描中，快門外圈即視角涵蓋率：被看過 30° 以上的表面佔比（30% 以下紅、60% 以下橘，之後綠），旁邊顯示百分比。
  - 「掃描設定」只剩快門左側一顆按鈕，下方直接標示目前模式（LiDAR 或相機模式）。
- **情境指示：**
  - 速度表只在接近模糊門檻時出現。
  - 熱圖圖例只在熱圖模式出現，標示視角跨度 0° 到 30°+（[量法](LIDAR_QUALITY_AND_PREVIEW.zh-TW.md#視角涵蓋熱圖)）。
  - 操作說明只在開頭幾幀出現。
- **橫向：** 高度 compact 時，快門欄移到右側，檢視面板在右下角，畫面中央保持淨空。

### 處理中

`FusionProcessingView` 保留分階段進度頁：進度環、百分比、階段清單、已用時間與影像數，並使用相同強調色。詳見[融合檢視](FUSION_REVIEW.zh-TW.md)。

### 掃描後檢視

優化後點雲佔滿螢幕。上方列有關閉、狀態膠囊、品質資訊鍵（有提醒時為警告色）與「顯示完整點雲」。浮動面板包含：
- 數據標籤：幀數、點數、影像重建結果；有平面圖時也會列出；
- 「匯出 3DGS 訓練資料」：匯出中顯示載入狀態，完成後改為「分享 .zip」；
- 「續掃」與破壞性的捨棄鍵。

手勢說明顯示四秒。

### 掃描詳情（歷史）

點雲或拍攝路線佔滿螢幕。
- 浮動切換鈕選擇「3D 點雲」或「拍攝影像」；標籤顯示影像數、點數與掃描模式，另有「顯示完整點雲」。
- 底部面板有品質資訊鍵與匯出或分享動作。優化進度（含百分比與「取消」）顯示在同一面板；匯出檔準備好時會出現提示。
- 「更多操作」仍包含空間尺度、優化與刪除。
- 路線回放改用玻璃疊層與強調色播放鍵；寬螢幕時照片與點雲左右並排。

### 平面圖、量測與選點

這些畫面的流程不變，改用共用的按鈕、卡片與底色。量測分成選點、校正／驗證、公尺匯出三張卡片；選點畫面的確認鍵是主要動作。

## 在 Simulator 檢查介面

Debug 版本接受以下啟動參數，不啟動 AR、不寫入掃描檔即可顯示介面狀態；Release 不含這些路徑。

| 參數 | 顯示內容 |
| --- | --- |
| `--preview-capture-controls` | 待機的掃描 HUD |
| `--preview-scanning` | 最擁擠的掃描 HUD：警告、速度表、熱圖、涵蓋率外圈 |
| `--preview-review` | 合成房間上的檢視面板，含提醒與影像重建結果 |
| `--preview-fusion` | 處理頁（見[融合檢視](FUSION_REVIEW.zh-TW.md)） |
| `--preview-history` | 掃描紀錄 |
| `--preview-scan-detail`、`--preview-scan-detail-photos`、`--preview-scan-detail-measure` | 最新一筆掃描的詳情頁：3D 分頁、影像分頁或空間尺度面板（App 的 `Documents/scans` 需有掃描） |
| `--compact-height` | 加上 compact 高度，檢查橫向排列 |

加上 `-app.language en` 可檢查英文。

```sh
xcrun simctl launch --terminate-running-process booted itri.fable --preview-scanning -app.language en
xcrun simctl io booted screenshot scanning.png
```

## 驗證與限制

- 已在 iPhone 16 Pro、iPhone SE（第 3 代）與 iPad Pro 11 吋 Simulator 上，以兩種語言、上述預覽狀態與兩筆已存掃描檢查。
- Simulator 沒有相機與 LiDAR，因此 HUD 下的即時 AR 提示與相機畫面、裝置旋轉、觸覺回饋、游標懸停與手機效能仍需實機確認。
- 橫向以 `--compact-height` 檢查，並非實際旋轉裝置。
